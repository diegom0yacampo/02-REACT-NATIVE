## Respuesta a la pregunta de comprensión
¿Por qué usarías `padding` en una tarjeta en lugar de `margin` para separar el texto del borde?

Respuesta:
El padding añade espacio entre el texto y los borde de la tarjeta y el margin la separacion es entre el texto y el boton
